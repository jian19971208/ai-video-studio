# 音轨、卡点与听审

- 适用级别：通用；音频生成/参考/编辑各依赖对应服务
- 前置能力：有声验收需audio.audition；剪裁/混音需media.edit；新音轨生成另核对实际音频服务
- 当前采用：有声交付；实用价值：4/5（项目内优先级，不是模型评分）。


先确定声音角色：简约器乐、人声台词、环境与转场音。不是每条片都堆机械音效；使用一条连续主音轨可保持统一。给定原BGM先听并记录真实段落/强拍，而不是猜“约12秒”。

保持原曲速度时，可在中段安排有意的间奏/环境声桥接，把重拍准确移到画面切点；不要随意全曲降速、也不要在一整段中混入无关机械氛围。保存音乐源时间与成片时间映射。

原曲参与生成只是条件，最终需要原曲就准确回铺；避免原生BGM与新BGM叠两层。台词音量与背景音乐分开，接点使用合理淡入出并检查截字、爆音和相位。音频授权按素材实际用途处理。

波形/RMS/相关性用于定位，完整试听才是声音验收。没有试听能力时该项待审，可交用户预览而不称全部通过。按纯静音设计的工作流标明silent-by-design。

## 操作步骤与产物

1. 输入已有BGM/对白或确定声音方案；先实际试听并标出起始、高潮、强拍与结束时间。无素材且需要新音乐/语音时，确认对应已接入的音频服务，视频模型存在不等于能独立生成任意音轨。
2. 建音画时间映射：源音轨起点、成片起点、使用长度、画面切点、淡入出及对白段。例：原曲8.4秒的重拍应落成片12秒，原速连续使用时源0秒应从成片3.6秒开始，前面以合适独立段衔接；实际试听接点再定。
3. 按[剪辑技巧](../editing/guide.md)在已验证处理服务上保留、替换或混音。简单source/replace与多轨混音分开核验；更换主BGM时不要叠加原生音乐。保存源文件与处理计划，不变速除非创意明确需要。
4. 完整试听最终交付文件，核对台词截字、重拍位置、响度突变、爆音和音画同步；波形用于定位，不能代替听审。输出音轨时间表与audio结论。

**失败处理**：无试听能力标pending并交可预览文件，必要听审未完成不报通过；缺混音服务不拿简单音轨替换冒充多轨。

执行环境、输入绑定、任务恢复按[公共执行方法](../execution.md)；所需服务配置按[服务能力核验](../../integrations/service-capabilities.md)。

商品宣传的实际试听不是生成或交付的必需门槛。当前工具无法试听时，保留生成原音轨，完成画面、商品和技术审查，在HTML报告中标明“声音待试听”；不因此停止制作、复制独立流程或额外索取批准，也不能声称声音已通过。
