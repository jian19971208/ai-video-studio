# 视频参考与白模

- 适用级别：方法通用；执行需模型视频参考能力；白模另需3D渲染
- 前置能力：video.reference.inspect, video.generate.reference
- 当前采用：专项；实用价值：3/5（项目内优先级，不是模型评分）。


视频参考负责连续速度、惯性、接触、运镜与节奏信息；商品照片负责外观，两者角色写清。素材可来自实拍、合适参考视频、上次实际生成片段，或缺参考时自建白模。

白模的用途是在没有合适视频时自行指挥动作，不是商品精准3D资产。先看白模自身是否合理，手鞋接触/重力/镜头路径是否正确，再给模型。通用鞋形可能影响商品比例；粗白模转成彩色视频并不说明动作被逐帧遵循。

15秒本地REF白模PV已运行：切镜约0/4.3/8.3/12.3秒，未严格跟0/4/7/10.5；鞋旋转弱、标注指错部件和字标重写。没有无白模同prompt对照，不能断言白模提升多少。默认商品展示不必额外做白模，只有预演本身解决了动作来源问题才用。

模板 `h3-video-ref-local/`演示六图片+视频槽，没有AG。换真实动作视频时保留商品真值参考；不要把参考视频字幕/错误产品传入续接。

## 操作步骤与产物

1. 先明确借用参考的内容：动作、接触、运镜或节奏。播放候选参考，裁取含完整所需动作的片段，记录原fps、帧范围和声音；只借动作时不要把其他产品当外观依据。
2. 没有合适动作参考且白模能解决预演需求时，再使用已配置的建模/渲染服务。制作动作关键状态、接触、镜头和切点，输出预演视频及可编辑场景/脚本；本包没有跨系统通用白模生成器，不默认服务器装有Blender。
3. 先审预演自身物理和构图，再用真实商品图承担外观参考。按[h3-video-ref-local](h3-video-ref-local/manifest.json)和[公共执行方法](../execution.md)上传并接入视频槽，核对加载fps、时间范围与prompt标签。
4. 运行后逐段比较实际运动/切镜与参考，而非只看是否从白变彩色；保存时间对照和商品偏差。输出预演、实际原片和review。

**失败处理**：白模动作本身错先修预演；商品比例被白模带偏则减少形状冲突或弃用该参考。模型未遵循不能通过事后加白模覆盖来声称成功。

执行环境、输入绑定、任务恢复按[公共执行方法](../execution.md)；所需服务配置按[服务能力核验](../../integrations/service-capabilities.md)。
