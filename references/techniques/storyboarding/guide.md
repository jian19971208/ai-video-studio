# 分镜与提前生图

自定义制作调用条件：storyboard_images默认false，先向用户说明可选用途，选择开启才生成新图片分镜；关闭仍可做文字镜头设计并复用用户原图，不强制生图或新图审定。固定预设按自己的步骤调用，不继承此默认开关。

- 适用级别：方法通用；生成设计图需要参考生图能力
- 前置能力：设计/复用需image.inspect；新生成参考分镜才需image.generate.reference
- 当前采用：核心；实用价值：5/5（项目内优先级，不是模型评分）。


每镜先明确用途：认出商品、理解一个结构/卖点、建立场景、完成剧情或品牌收束。记录时长、景别、主体动作、相机路径、光线、背景、文字、安全边距与关键保真部件。

原图能承担商品局部时直接用原图；人物、穿搭和场景另生成设计图。生图参考真实产品，不让视频重新发明未审过的设计。分镜合图用于全片布局；拆格后保留独立清晰图，检查裁头裁鞋、格线/字幕、产品结构、小字和颜色。生成图不合格先修图，不让REF/AG忠实复制错误。

三类约束分开：商品结构必须保留；人物/场景身份跨镜一致；背景、光效、动作是可变化内容。鞋广告不需要脸时用腰以下/膝以下/鞋特写，让产品占足画面；这是商品展示策略，不限制剧情类必须露脸。

静态布局不能替代连续运动设计。需要运动时写清从哪个角度到哪个角度、运动方向与速度，预留完整鞋边界。默认每镜一个主要动作；复杂动作可拆短，但不能把所有动态裁掉后声称解决了质感。

输出storyboard.json与source-review.json，问题标明来源。通过才交生成。没有生图能力而已有完整合格分镜时可直接复用；工作流要求新设计则必须先补能力。

## 操作步骤与产物

1. 根据目标时长写信息时间线：每段只传达一个内容，注明动作、运镜、开始/结束状态、切点与文字用途；合计覆盖本次时长。先定整段生成还是有实际必要拆段，不能按分镜数自动拆任务。
2. 将真实商品多角度图作为商品依据，分别设计必要的场景/上脚构图。向已选参考生图服务提供原图、镜头说明、画幅和关键保真点；不指定用户必须用某家生图工具。
3. 每次查看独立设计大图与商品原图，核对轮廓、部件、颜色、字标、透视、接触及边界。合图需拆成独立参考时检查裁切质量；局部实拍够用则直接引用，不无意义再生图。
4. 失败图只针对具体错误修订；通过后保存设计图、顺序、各图角色及审图结论，交给REF与提示词技巧。已有合格设计图时可复用，按工作流是否要求新图决定。

**验收与失败处理**：设计图必须同时成立为画面和商品参考；一张漂亮但结构错误的图不能进入生成。生图服务不接受参考图时列能力缺项，而非改成纯文生图冒称一致。

执行环境、输入绑定、任务恢复按[公共执行方法](../execution.md)；所需服务配置按[服务能力核验](../../integrations/service-capabilities.md)。
