# LoRA、控制节点与局部编辑

- 适用级别：模型/节点/平台专属，可选扩展
- 前置能力：video.generate.reference
- 当前采用：退出默认，按专项需求；实用价值：2/5（项目内优先级，不是模型评分）。


LoRA曾验证能加载和生成；缺少无LoRA同seed对照时不得称提升了某个比例。训练、数据清洗、权重上传、模型基底兼容与费用是独立任务，不随普通出片自动启动。RH的LoRA上传及平台文件名不能直接当本地Loader文件名。

ControlNet/姿态/深度/遮罩等是潜在能力，不因ComfyUI节点目录有名字就认为当前H3或目标权重支持。要有兼容模型、具体输入控制和成功执行图；本包没有把未验证ControlNet加入默认流程。

“只改视频某几秒”优先通过生成替换镜头并编辑接点实现。模型内任意区间编辑需实际接口，不把AddGuide描述成通用修复器。精确Logo与说明文字采用可控后期资产，但不得覆盖错误产品结构假称模型保真。

## 操作步骤与产物

1. 明确需要改变的能力与可用模型基底，确认训练/加载/区间编辑哪一项已经授权。检查实际提供方是否开放LoRA或控制输入，不因技术名称存在就自动尝试。
2. 已有LoRA时核对基底、版本、权重文件、Loader、强度和兼容提示词；Control/遮罩需确认控制模型、预处理输入、尺寸时间轴和可用执行图。训练或安装是单独部署事项。
3. 有实际可运行图才做授权范围内的针对性对照，保存基线、改动和回执。本包没有通用ControlNet/局部视频编辑图，未适配时标待接入，不虚构节点。
4. 局部替换优先复用其他合格段，仅对失败范围生成候选；按[剪辑](../editing/guide.md)检查接点，再按[审查](../quality-review/guide.md)核对改动是否损害其他结构。

**验收与失败处理**：以目标问题是否改善为准，加载成功不算质量改善；无基线不声称百分比提升。失败记录具体兼容性或副作用，不并入默认流程。

执行环境、输入绑定、任务恢复按[公共执行方法](../execution.md)；所需服务配置按[服务能力核验](../../integrations/service-capabilities.md)。
