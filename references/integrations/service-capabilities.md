# 服务配置与实际能力核验

“自建”指用户已部署且可访问的服务，不限同机、不限Ubuntu，也不限ComfyUI。客户端能运行Go工具，只说明客户端可用；模型、节点和渲染/编码依赖须在真正执行任务的服务器上具备。SSH是另行部署维护的手段，不是日常API使用的前提。

## 两阶段检查

初次登记只检查地址、认证、服务身份及可读接口；RH核对站点、Key类型及两种余额。此时报告已连通/已登记，不承诺所有制作能力。开始任务后，再按所选技巧与有效设置核对必要能力。未选择超分或白模就不要求安装超分模型或Blender，不把一台服务缺少另一类能力当接入失败。

| 操作 | 自建服务需要实际具备 | RH需要实际具备 |
|---|---|---|
| 参考生图 | 支持参考图的图像模型/节点或独立图像API、相应认证和输入输出 | 支持该功能的原生图或商业模型API，核对计费；不能用视频模型代替 |
| H3 REF/FL/Guide | 对应模式权重、兼容编码器、视频/音频VAE、实际节点与资源；Guide额外查端口 | 当前算力节点/权重/端口及选定参数可用，历史模板不能代替当前库存 |
| 视频参考/续接 | 模型实际接收视频或帧组，解码上传可用，核对长度/fps/槽位 | 同样检查实际入口，不因API能上传视频就推断模型能用视频参考 |
| 白模 | 可用的3D建模/渲染服务或已安装渲染工具，以及可编辑场景资产 | 不默认平台具有白模制作能力；可接已配置渲染服务，生成后上传参考 |
| 剪辑/字幕/音轨 | 已部署处理节点或独立媒体API；字幕字体与渲染、混音、编码各自核验 | 核对具体原生节点/商业处理API，能拼接不等于能字幕或复杂特效 |
| 超分 | 指定模型/Loader、推理设备、分段容量、编解码与音轨恢复 | 原生超分图核对权重/算力；Topaz等商业服务核对接口、共享Key及钱包预算 |
| 审查 | 宿主/可访问服务能看图、播放、试听、探测；分别记录 | 云任务成功仅代表执行完成，审查仍依赖实际查看与听审能力 |

## 怎样判断已具备

ComfyUI读取system_stats/queue/object_info和实际Loader枚举；见[自建接入](self-hosted-comfyui.md)。其他自建服务读取对应API说明、只读状态/能力响应；ComfyUI的doctor不能代替其他服务检查。文件路径在服务器与客户端不同，先验证上传、返回引用及输出下载路径。自建节点若内部调用外部商业API，还需该服务的认证、网络和费用，不应登记成本地零费用模型。

每项证据注明提供方/profile/API地址、节点或接口、模型/版本、检查时间、规格适用范围和限制。已配置、接口可达、节点可见、历史运行成功、本次设置可用分别描述；没有显存/兼容性证据时标未知，不伪造通过。declare不是verified；一次doctor成功不验证全部技巧。缓存换接入/认证/节点/模型或任务参数后重查，沿用[前检](../preflight.md)的记录有效期。

## 缺项怎么处理

给出具体缺的模型/节点/接口/字体/资源，优先指向对应接入说明和已知官方安装资料，由管理员处理。常规出片不安装、下载模型、SSH修改服务或重启。已有合格素材可按工作流规则复用；可选增强跳过并说明，用户明确要求的步骤缺项则停该步骤。换模型/服务或改创意需要明确方案，不能自动降参或切钱包执行。

本页是Agent核验要求，Go工具只覆盖其已实现探测范围，不声称已自动检查所有外部服务、显存或商业接口。生图独立接入见[图片与素材](image-and-materials.md)，新服务见[适配器扩展](adapter-contract.md)。
